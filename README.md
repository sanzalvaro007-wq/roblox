# Mimic Manor

Juego de terror asimétrico y escondite para Roblox: una Anomalía que se transforma en muebles contra Investigadores que intentan escapar de una mansión victoriana.

## Estructura

- `src/server`: servicios del servidor (ServerScriptService)
- `src/client`: controladores del cliente (StarterPlayerScripts)
- `src/shared`: módulos compartidos (ReplicatedStorage)
- `docs/`: documentación del juego; ábrela como vault de Obsidian

## Empezar

1. Instala [Rojo](https://rojo.space) y el plugin de Rojo en Roblox Studio.
2. Ejecuta `rojo serve` en la raíz del repo y conéctate desde Studio.
3. Lee `docs/prompt-diseno-mimic-manor.md` para arrancar el diseño.
